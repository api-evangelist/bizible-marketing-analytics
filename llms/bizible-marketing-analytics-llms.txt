# Bizible Marketing Analytics

> Bizible was a B2B marketing attribution and revenue analytics platform that connected marketing
> activity to pipeline and revenue across advertising, web, CRM, and marketing-automation channels.
> Acquired by Marketo in 2018 and subsequently by Adobe, the product ships today as Adobe Marketo
> Measure (formerly Bizible). The bizible.com domain 301-redirects to Adobe and its product
> documentation lives on the Adobe Experience League. There is no standalone public developer
> portal, OpenAPI, GraphQL SDL, MCP server, or API reference for this brand.

## What this company actually exposes

The only public, machine-touchable surface is a client-side JavaScript tracking tag served from
Bizible's own CDN, with a two-call in-page API. There is no server-side HTTP API to call.

- [Marketo Measure JavaScript (bizible.js)](https://cdn.bizible.com/scripts/bizible.js): The
  tracking script, added before the closing `</head>` on every page. Build 4.26.08.05,
  CDN Last-Modified 2026-08-07. The URL is unpinned — it always serves the latest build.
- `window.Bizible.Push('Consent', true|false)`: grants or withdraws tracking consent when the
  script tag carries `data-requires-user-consent="true"`.
- `window.Bizible.Push('User', { eMail: email })`: associates the current visitor with a known
  email address.
- Collection host: `https://a.bizible.com` — where the tag posts touchpoint data. Anonymous
  requests are refused (HTTP 403); there is no documented request/response contract.
